# Release validation · 0.1.2

发布副本与已安装副本分离；发布清单不设置机器目录、profile 目录或自动证据文件。依赖链接在解压目录内重新创建，ZIP 不存储指向开发机器的链接。

既有实现验证：28 个回归用例、12 个入口导入、五个原生组件激活、四类组件及核心的独立开关、PowerShell/Bash 跨调用状态、专用 Git worktree。Codex 最小在线提示曾成功；Claude 在线调用尚未验收，需要自行登录。未声称逐一验证其他插件全部功能，也未把未来版本范围声明等同于完整宿主实测。

发布副本的新增检查包括独立目录模块导入、回归测试、依赖本地性、脱敏扫描、解压后离线恢复与校验。具体结果由交付的 `release-validation.json` 汇总，仅记录版本、检查项和结果，不包含用户、路径、PID、会话或账户信息。

界面组件数据与真实宿主开关有运行证据；视觉及明暗主题未自动验收。静态组合检查不执行全部 YAML 表达式，完整装配应在实际宿主验证。

仓库与 ZIP 不带历史会话、运行日志、profile、部署备份、构建缓存、source map 或凭据。原始本机验收报告不进入公共交付。
